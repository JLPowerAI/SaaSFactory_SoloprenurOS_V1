# ⚠️ CRITICAL WARNING - AGENT TO AGENT (A2A) PAYMENTS
Los flujos de pago tradicionales están diseñados para requerir intervención humana (tarjetas de crédito, OTPs, interfaces web). 
Conectar un agente autónomo de IA a estos rieles tradicionales romperá la lógica del sistema y generará bloqueos por comportamiento anómalo.
La orquestación de pagos de máquina a máquina requiere una infraestructura de rieles dedicados que no dependa de interfaces de usuario. No intentes programar esto directamente con pasarelas web estándar si buscas verdadera autonomía agéntica.
